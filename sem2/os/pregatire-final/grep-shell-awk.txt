1. Write an AWK command that displays the sum of all the numbers in a text file whose lines consist of sequences of digits separated by spaces.

grep -E '^([0-9]? +[0-9])+ *$' nr.txt | awk 'BEGIN {sum=0} {for (i=1; i<=NF; ++i) sum+=$i} END {print sum}'

2. scrieti un grep care ia grupurile de cate 2 cuvinte, separate de un singur spatiu, care sunt formate doar din litere mici si fiecare cuvant contine cel putin 2 vocale

3. scrieti un sed care inlocuieste prima aparitie a caracterului A cu caracterul B

sed -E "s/^([^A]*)([A])/\1B/" text.txt
